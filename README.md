# CookingMenu
晩御飯考えるやつ

冷蔵庫の在庫から献立を提案する、スマホ向けの Web アプリです。
`index.html` 1ファイルで動き、外部への通信はしません（在庫データはブラウザの localStorage に保存）。

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JavaScript） |
| `recipes.json` | レシピデータ。自由に追加・編集してください |

## 使い方
1. 「食材を登録」で食材をタップして選び（複数可）、賞味期限を入れて「追加」
2. 在庫一覧では、賞味期限が3日以内（期限切れ含む）の食材が赤く上に並びます
3. 調理時間と気分を選んで「献立を提案」
   - 在庫で揃う割合が高く、期限が近い食材を使うレシピほど上位に、最大3件表示します

## recipes.json の編集方法
1件ごとに次の形で書きます。

```json
{
  "name": "肉じゃが",
  "ingredients": ["じゃがいも", "玉ねぎ", "にんじん", "豚肉"],
  "time": 30,
  "type": "和食",
  "url": "https://example.com/recipe"
}
```

| 項目 | 説明 |
| --- | --- |
| `name` | 料理名 |
| `ingredients` | 主な食材（調味料は入れない）。**アプリの食材リストと同じ表記**で書く（下記） |
| `time` | 調理時間（分、数字） |
| `type` | `和食` / `洋食` / `中華` / `エスニック` のどれか |
| `url` | 公式サイトのレシピページ URL。空文字 `""` にするとリンクを表示しません |

注意:
- 全体は `[ ... ]` で囲み、各レシピの間はカンマ `,` で区切ります。最後のレシピの後ろにはカンマを付けません。
- 食材の照合は完全一致です。`豚こま肉` ではなく `豚肉` のように、リストの表記に合わせてください。

使える食材名（`index.html` の `CATALOG` に定義。ここに追加すれば登録画面にも出ます）:

- 野菜・きのこ: 玉ねぎ, にんじん, じゃがいも, キャベツ, 白菜, 大根, ねぎ, ピーマン, なす, トマト, きゅうり, ほうれん草, ブロッコリー, もやし, レタス, かぼちゃ, しめじ, えのき, ごぼう, にら
- 肉: 豚肉, 鶏もも肉, 鶏むね肉, 牛肉, ひき肉, ベーコン, ハム, ウインナー
- 魚介: 鮭, さば, ぶり, えび, いか, ツナ缶
- 卵・乳製品・大豆: 卵, 牛乳, チーズ, バター, 豆腐, 油揚げ, 納豆
- 主食・その他: ごはん, うどん, パスタ, 中華麺, カレールウ, キムチ, こんにゃく

## GitHub Pages で公開する
1. この2ファイルを `main` ブランチに push
2. GitHub のリポジトリで Settings → Pages → Build and deployment
3. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/CookingMenu/` で開けます

※ `index.html` をファイルとして直接開くと `recipes.json` を読み込めません（ブラウザの制限）。
手元で試すときは `python -m http.server` などでローカルサーバーを立てて開いてください。
